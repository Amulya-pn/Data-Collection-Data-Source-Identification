# 📊 Dataset Understanding & Data Types Analysis

## 📖 Introduction

This project was completed as part of an AI & ML Internship Task focused on understanding datasets and different data types using Python.

In Data Science and Machine Learning, understanding the structure of data is one of the most important first steps before building any model. This project demonstrates how to explore a dataset using Python libraries like Pandas and NumPy.

The notebook analyzes the dataset by checking:
- Dataset structure
- Data types
- Numerical and categorical variables
- Missing values
- Unique values
- Statistical summary

This task builds a strong foundation in Exploratory Data Analysis (EDA).

---

# 🎯 Objectives

The main objectives of this project are:

✅ Load the dataset using Pandas  
✅ Understand dataset dimensions and structure  
✅ Identify numerical and categorical columns  
✅ Check data types of each column  
✅ Find missing/null values  
✅ Generate statistical summaries  
✅ Explore unique values in categorical columns
